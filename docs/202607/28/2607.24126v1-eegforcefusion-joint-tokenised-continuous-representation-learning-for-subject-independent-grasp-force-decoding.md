## 摘要
脑机接口为神经活动与外部设备之间建立了联系，使得利用非侵入性脑电图（EEG）恢复运动功能并促进人机交互成为可能。然而，由于复杂的时序动态、较高的跨被试变异性以及现有方法的泛化能力有限，连续抓取力解码仍面临挑战。为此，我们提出了一种混合EEG解码框架，该框架联合建模连续表示与标记化表示，从而能够捕捉细粒度的神经结构以及长程时序依赖。所提出的方法将卷积-循环表示学习、基于量化的标记化以及基于Transformer的时序建模集成到一个统一的基于融合的回归架构中。在WAY-EEG-GAL数据集上，采用严格的留一被试交叉验证，离线设置下实现了$R^2$ = 0.817，模拟实时评估中实现了$R^2$ = 0.793，且延迟适合实时部署。这些结果展示了强大的跨被试泛化能力，并突显了混合连续-标记化表示在辅助机器人、神经康复和人机交互中用于基于EEG的实时力解码的实用性。

## Abstract
Brain-machine interfaces provide a link between neural activity and external devices, enabling restoration of motor function and advancing human-machine interaction using non-invasive electroencephalography (EEG). However, continuous grasp force decoding remains challenging due to complex temporal dynamics, high inter-subject variability, and limited generalisation of existing approaches. To address this, we propose a hybrid EEG decoding framework that jointly models continuous and tokenised representations, enabling capture of both fine-grained neural structure and long-range temporal dependencies. The proposed approach integrates convolutional-recurrent representation learning, quantisation-based tokenisation, and transformer-based temporal modelling within a unified fusion-based regression architecture. Experimental evaluation on the WAY-EEG-GAL dataset under strict leave-one-subject-out conditions achieves $R^2$ = 0.817 in offline settings and $R^2$ = 0.793 in simulated real-time evaluation, with latency suitable for real-time deployment. These results demonstrate strong cross-subject generalisation and highlight the practicality of hybrid continuous-tokenised representations for real-time EEG-based force decoding in assistive robotics, neuro-rehabilitation, and human-machine interaction.

## 2. 方法论
- **核心思想**：将 EEG 信号同时编码为连续嵌入（保留精细结构）和离散 token 序列（面向结构化时序建模），通过融合二者实现多尺度神经动力学的联合建模。
- **关键技术细节**：
  - **预处理**：1-40 Hz 带通滤波 + 50 Hz 陷波 + 共同平均参考；选取 7 个运动相关通道；事件对齐的滑动窗口（长度 T=32）。
  - **CNN-GRU 编码器**：嵌入维度 128；卷积层提取空谱特征，GRU 层建模短时依赖；使用多目标损失（力回归、特征对齐、对比学习、时间一致性、方差项），权重 α=0.3, β=0.2, γ=0.05, δ=0.1, η=0.1。
  - **离散 Token 化（FSQ）**：将连续嵌入投影到低维空间，采用有限标量量化（Finite Scalar Quantization）离散化为固定数量的 token（K=8 级，token 维度 24）。无学习码本，避免码本坍塌，适合跨被试泛化。
  - **Transformer 时序建模**：将 token 序列输入浅层 Transformer（d_model=128, 4 头, 4 层），作为时序特征提取器；训练时使用双向注意力（离线）或因果掩码（模拟实时）；仅训练约 5 个 epoch 便冻结，防止过拟合到被试特定分布。

- **公式流程**：
  - 编码：`e = f_enc(X)`，`X ∈ R^{T×C}`
  - Token 化：`z = f_proj(e)`, `z_q = Quantize(z)`
  - 时序建模：`h = f_tr(z_q)`

## 6. 主要结论与发现
- **性能**：离线 LOSO 达 R²=0.817，模拟实时 LOSO 达 R²=0.793，超过最强基线 EEGForceMap+NNR（R²=0.785）3.2%。
- **Transformer 作为浅层特征提取器**：训练约 5 epoch 即过拟合，冻结后用于融合可有效防止被试特异性过拟合，且对超参数不敏感（5 种配置均值 R² 仅 0.788~0.803）。
- **融合策略的有效性**：全融合（Embedding + Δe + Transformer）与编码器单独性能相当（R²≈0.81），未提升但提供了可冻结、可复用的时序骨干，适合实时推理。
- **离散 token 化的作用**：提供稳定、共享的词汇表，使 Transformer 能在跨被试中保持泛化，且隐式正则化嵌入漂移。
- **实时性**：推理延迟约 1.6–2 ms/样本，满足实时闭环需求。
