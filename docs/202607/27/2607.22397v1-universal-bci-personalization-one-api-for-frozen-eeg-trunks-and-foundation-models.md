## 摘要
冻结的EEG编码器层出不穷；每个模型单独微调默认设置无法扩展。我们提出Nimbus个性化器：一个统一的接口，从编码到贝叶斯头部再到BrainState（可选的仿射中间层），它位于异构的冻结骨干网络上，无需为每个架构提供新的个性化堆栈。论点（系统层面）：贡献在于与骨干网络无关的API——而不是作为机器学习新颖性的嵌入上的LDA——因此OEM厂商可以一次性集成并切换骨干网络。证据：同一接口在五个经典骨干网络（EEGNet、Shallow、Deep、Conformer、ATCNet）上运行，涵盖四个MI数据集（18个单元），并在同一个性化器下运行在一个基础编码器（REVE）上。在存在嵌入容量的情况下，头部是一个廉价的默认中间点，相比热启动微调或PEFT，适应时间成本低数个数量级，同时恢复了大部分微调精度的提升；仅当数据干净时才进行校准在12/18个单元中成立。头部的增益支持了API在存在容量时的有用性。主体级置信区间确定了最清晰的数据集，在其他情况下为零。所有结果均为探索性（主体级自助法，无验证性检验）；何时升级适应的决策逻辑在我们的控制层配套工作中讨论。

## Abstract
Frozen EEG encoders proliferate; per-model fine-tune defaults do not scale. We present Nimbus Personalizer: one contract encode to Bayesian head to BrainState (optional affine mid-tier) that sits on heterogeneous frozen trunks without a new personalization stack per architecture. Thesis (systems): the contribution is the trunk-agnostic API - not LDA-on-embeddings as an ML novelty - so OEMs integrate once and swap trunks. Evidence: the same surface runs on five classical trunks EEGNet, Shallow, Deep, Conformer, ATCNet x four MI datasets (18 cells) and on a foundation encoder (REVE) under the same Personalizer. Where embedding capacity exists, the head is a cheap default mid-point versus warm-start fine-tune or PEFT, costing orders of magnitude less adaptation wall time while recovering much of the fine-tune accuracy gain; calibration-only-when-clean holds in 12/18 cells. Head gains are supporting evidence that the API is useful where capacity exists. Subject-level confidence intervals identify the clearest dataset and span zero elsewhere. All results are exploratory (subject-level bootstrap, no confirmatory tests); the decision logic for when to escalate adaptation is addressed in our companion work on the control layer.

### 6. 论文的主要结论与发现

1. **API 通用性**：同一个 Personalizer 接口无需修改即可运行在5个经典骨干和1个基础模型（REVE）上。
2. **廉价头部有效**：在存在嵌入容量的情况下，L1/L2头部适应恢复了大部分微调精度增益（恢复率约65%~90%），同时适应时间短几个数量级（L3/L1墙壁比14×~40×）。
3. **cal-only-when-clean 是可靠的默认项**：在压力水平0时，12/18个单元上L0（仅校准）是效用最优；在严重压力下L1/L2更具优势（13/18单元头部增益为正）。
4. **严格序贯升级条件性**：要求clean→L0且severe→L2的严格序贯仅在5/18单元成立，表明升级策略应基于数据集和骨干容量，而非固定规则。
5. **头部选择依赖数据与压力**：LDA是安全的默认值；QDA优势局限于BNCI数据集+通道混合压力，在其他压力家族上QDA没有一致增益。
6. **基础模型适用**：REVE在相同API下运行，头部仍然比全微调便宜得多（墙壁比8×~51×），且准确率在大多数单元上接近或超过LoRA/最后一层微调。
7. **不确定度校准**：在严重压力下，LDA头部的期望校准误差（ECE）显著低于冻结骨干（BNCI: 0.22→0.10；Zhou: 0.27→0.09）。

### 7. 优点：方法或实验设计上的亮点

- **系统级贡献清晰**：强调API本身是产品，而非新分类器，便于工业落地（OEM一次性集成，切换骨干）。
- **严格的实验控制**：固定骨干冻结、标签预算、压力水平、效用函数，使多骨干成本对比客观。
- **丰富的对比组**：包括L0/L1/L2/L3、线性探针、LoRA、最后一层微调、全微调，在经典骨干和基础模型上均有覆盖。
- **统计透明度**：使用主体级自助法置信区间，并明确指出探索性性质，避免过度声明。
- **头部家族分析**：全面评估LDA/QDA/Softmax，并跨4种压力家族复现，避免了单一压力下的误导结论。
- **效用函数设计合理**：同时考虑准确率、适应时间和标签成本，贴近真实部署场景。
- **不确定性输出**：BrainState提供结构化预测（意图、置信度、不确定度、备选），可用于下游决策。

### 8. 不足与局限

- **实验覆盖有限**：
  - 仅使用了运动想象任务（MI），未覆盖其他BCI范式（如P300、SSVEP）。

  - 基础模型（REVE）仅在两个数据集上测试，且BNCI因3通道接近随机而未使用。
- **统计力量不足**：
  - 主体数量少（n=4~18），且多数置信区间包含零。

- **未报告完整算力**：GPU型号、训练总时长缺失，不利于可重复性。
- **无开放代码/模型**：论文提到内部基准套件，但未公开，限制了第三方复现。
- **控制层决策未涵盖**：何时升级适应的逻辑仅提及配套工作，本文未提供实用指南。
