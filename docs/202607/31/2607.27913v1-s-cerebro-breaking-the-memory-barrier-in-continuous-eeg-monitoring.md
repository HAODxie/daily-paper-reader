## 摘要
基础模型为脑电图（EEG）分析提供了一种有前景的范式，利用了来自海量无标注数据集的通用表征。然而，基于Transformer的架构面临一个关键瓶颈：全局注意力机制将注意力内存状态与信号持续时间耦合，导致连续监测期间内存溢出。为解决这一问题，我们引入了S-CEReBrO（流式CEReBrO），这是专为连续监测设计的CEReBrO架构的演进版本。我们提出的窗口交替注意力机制将注意力计算分解为固定大小的时空窗口，确保KV缓存内存恒定，因为只有活动窗口需要驻留注意力映射。实证缩放分析证实，窗口交替注意力可以处理比全自注意力长100倍、比低秩线性注意力长3倍的信号。与长上下文中的低秩线性注意力相比，窗口交替注意力仅需其55%的内存，同时推理吞吐量提高2.1倍。S-CEReBrO在超过12,000名受试者的超过25,000小时记录上进行了预训练，在11个下游任务中的7个上达到了最先进性能，且参数量最多减少60%。这项工作向着实现高效、可泛化且连续的脑电监测迈出了重要一步。随附的代码仓库已公开。

## Abstract
Foundation models offer a promising paradigm for Electroencephalography (EEG) analysis, leveraging generalizable representations from vast unlabeled datasets. Yet, Transformer-based architectures face a critical bottleneck: global attention mechanisms couple the attention memory state to the signal duration, causing memory overflow during continuous monitoring. To address this, we introduce S-CEReBrO (Streaming CEReBrO), an evolution of the CEReBrO architecture designed for continuous monitoring. Our novel Windowed Alternating Attention mechanism factorizes attention computation into fixed-size spatiotemporal windows, guaranteeing constant KV cache memory as only the active window requires resident attention maps. Empirical scaling analysis confirms that windowed alternating attention can process signals 100X longer than full self-attention and 3X longer than low-rank linear attention. Compared to low-rank linear attention on long contexts, windowed alternating attention requires 55% of the memory while increasing inference throughput by 2.1X. Pre-trained on >25,000 hours of recordings from >12,000 subjects, S-CEReBrO achieves state-of-the-art performance on 7 of 11 downstream tasks, with up to 60% fewer parameters. This work represents a significant step toward the realization of efficient, generalizable, and continuous EEG monitoring. An accompanying code repository is available.

# S-CEReBrO 论文总结

## 1. 核心问题与整体含义

- **研究背景**：脑电图（EEG）在连续监测（如癫痫检测）中数据量会随观察时间无限增长，而通道数（C）相对固定。虽然 EEG 基础模型已经在多个下游任务上表现优异，但主流的 Transformer 架构依赖全局注意力，其注意力内存状态（KV 缓存）与信号时长 T 耦合，导致长时间监测时发生内存溢出，无法支持真正连续的部署。
- **核心问题**：如何在不损失性能的前提下，打破连续 EEG 监测中的内存瓶颈，使 Transformer 基础模型能够处理超长信号且保持常驻内存可控。
- **整体含义**：该论文提出 S-CEReBrO（Streaming CEReBrO），通过“窗口化交替注意力”（Windowed Alternating Attention）机制，将注意力计算限制在固定大小的时空局部窗口内，实现 KV 缓存内存与信号时长无关，从而将基础模型的应用扩展到连续、长时监测场景，为未来实时 EEG 分析奠定了基础。

## 2. 方法论

- **核心思想**：摒弃全局注意力，引入局部性先验。将 EEG 的 2D 时空结构（通道 × 时间）分解为两个交替的注意力阶段——窗口化时间注意力和窗口化空间注意力。每个查询只与固定大小的邻域内的键-值对交互，从而保证驻留内存恒定；通过多层堆叠和通道/时间间的交替传播，依然能间接建模长距离依赖。
- **关键技术细节**：
  - **时空 Tokenization**：对每个通道应用长度为 L、步长为 S 的滑窗生成补丁（patch），经共享卷积编码器映射为潜在嵌入；加上可学习的时间位置嵌入（索引矩阵）和基于 3D 电极坐标的连续空间嵌入（通过共享 MLP），得到输入张量 \(H^{(0)} \in \mathbb{R}^{C \times N_p \times d_e}\)。
  - **窗口化时间注意力（WTA）**：对每个通道独立进行时间维度的注意力，每个时间查询 \(q_{c,i}\) 只关注局部时间邻域 \(\mathcal{N}_t\)（窗口大小 \(w_t\)）。邻域通过层相关的膨胀因子 \(d_l\) 和移位因子 \(s_l\) 定义，从而在不同层覆盖更广的上下文但不增加内存开销。
  - **窗口化空间注意力（WSA）**：在同一时间索引上，每个通道查询只关注局部通道邻域 \(\mathcal{N}_s\)（窗口大小 \(w_s\)），同样使用膨胀和移位因子，实现跨通道信息交互。WSA 充当“时间桥”，让不同局部时间窗口的信息在层间传播。
  - **常数内存管理**：通过 FIFO 流式处理，逐出超出固定窗口的陈旧 token，使得计算缓冲区大小仅依赖窗口尺寸（\(w_t\) 和 \(w_s\)），而不再依赖信号总长度 T。总计算复杂度为 \(O(CT)\)，KV 缓存内存为 \(O(1)\)（常数级）。相比之下，标准交替注意力内存为 \(O(T)\)，复杂度 \(O(CT(C+T))\)。
  - **预训练**：采用掩码自编码（MAE）。随机掩码部分 patch，由模型重建；损失为掩码和可见位置重建损失的加权和。
- **公式表达（文字描述）**：
  - WTA 输出：对每个查询，在局部时间邻域内计算 softmax(Q·Kᵀ/√d) 后与值加权求和。
  - WSA 输出：类似地，在局部通道邻域内进行注意力聚合。

## 3. 实验设计

- **预训练语料**：>25,000 小时 EEG，>12,000 名受试者。来源包括 TUEG、SEED 系列、BOAS、SleepEDFx、BCI-NER、GWD 等，涵盖 2–62 通道、不同参考方案。全部重采样到 200 Hz，按 30 秒窗口处理。为避免数据泄漏，严格排除 TUAB 的受试者。

## 7. 局限性

- **注意力窗口的超参数依赖人工设定**：\(w_t\)、\(w_s\)、膨胀因子和移位因子的具体取值需要根据数据集特性调整。论文虽给出了默认配置，但未讨论窗口尺寸对性能的敏感性分析，也没有自适应机制，这限制了模型在新场景中的通用性和部署便捷性。
- **流式推理仅停留在架构仿真层面**：虽然内存/延迟实验验证了常数级内存特性，但实际部署中还需考虑实时滑动窗口的调度、数据到达不均匀性、多层 FIFO 状态维护等工程细节，论文均未涉及。
- **预训练数据与评测基准的领域跨度有限**：预训练语料以临床 EEG 为主，而下游评测中包含了大量 BCI 和状态监测任务；虽然结果表现良好，但模型对非临床采集设备、不同采样策略（如干电极、移动设备）的鲁棒性未被单独验证。
- **未与更大规模基础模型对比**：所有基线参数量均限制在 10M 以下，未与 LaBraM 的 Large 版本（约 100M+）或 BIOT 的扩展版比较，因此无法证明 S-CEReBrO 在相对更大的参数量下仍能保持内存优势。论文的立场是“轻量级适合连续监测”，但并未说明参数量增大时窗口化注意力是否依然有效。

## 8. 实际意义

- 对临床连续脑电监测（如癫痫重症监护、睡眠监测）而言，S-CEReBrO 的常数级内存特性使得模型可以“无期限”地运行在边缘设备上，不需要定期重启或清空缓存，这是现有 Transfomer 架构无法做到的。
- 对 EEG 基础模型社区而言，该工作证明了一个重要观点：全局注意力并非基础模型的必需组件。通过引入合理的时空局部性先验，可以在显著降低资源消耗的同时维持甚至提升下游任务性能，为后续超长序列系列基础模型的架构设计提供了新思路。
- 窗口化交替注意力亦可作为即插即用模块，替换现有 EEG Transformer 模型中的全注意力层，使得原本只能处理数分钟数据的模型可以直接扩展到数小时乃至更长尺度，具有较强的工程迁移价值。

## 10. 与同类工作的比较

- 相对于 LaBraM 和 BIOT，S-CEReBrO 首次专门针对“连续/流式”场景设计注意力机制，而不是泛泛地宣称支持长信号。LaBraM 使用窗口化全注意力（时间滑窗），缓解了序列长度的二次复杂度，但其注意力窗口内仍包含所有通道，内存随通道数线性增长，且未提供常数级流式推理方案；BIOT 采用分层下采样全局注意力，模型容量和序列长度仍受全局交互限制。
- 与线性注意力（如 Performer、Linear Transformer）相比，S-CEReBrO 避免了低秩近似造成的性能损失，在 11 个任务上与全注意力相当甚至更好，同时保持了严格的局部窗口限制，而非依赖近似核函数。
- 与经典的 CNN 架构（如 EEGNet、SPaRCNet）相比，S-CEReBrO 作为预训练基础模型在跨任务迁移上的优势明显，但窗口化注意力带来的额外推理开销在极短序列（如小于 1 秒）上可能并不比纯 CNN 有优势，更适合中长序列场景。

## 11. 总体评价

S-CEReBrO 是 EEG 基础模型向连续监测迈进的一个扎实工程贡献。其核心价值不在于提出全新的注意力范式，而在于将已有“局部注意力”“交替注意力”思想与 EEG 特有的时空二维结构深度结合，并完成了从预训练到多任务评估的全链路验证。尽管存在窗口超参数人工设置、工程化验证不足等缺陷，但该工作在“内存-性能”权衡上给出了清晰的平衡点，证明了轻量级模型在长时 EEG 任务中的可行性，为该方向的后续研究提供了良好的基线和可扩展架构。
