## 摘要
大型音频语言模型（LALM）在通用语音理解方面表现出色；然而，将它们适应到语音情感识别（SER）等细粒度任务仍然是一个重大瓶颈。当前的参数高效微调（PEFT）方法通常在平坦的欧几里得空间中运行，而这种几何结构无法捕捉情感线索的多粒度特性，这些线索范围从低级韵律到高级语义。为解决这一问题，我们提出了HyPASE，一种基于LALM的SER的双曲PEFT框架。HyPASE利用庞加莱球模型，将双曲半径作为表示粒度的显式代理。该框架由两个核心组件组成：用于分层自适应权重调制的双曲几何适配器（HGA），以及将多尺度特征压缩为紧凑音频前缀的情感感知多容量跨模态聚合器（EMCA）。在标准基准上的实证结果表明，HyPASE在MELD上的所有指标均优于欧几里得PEFT基线，并在IEMOCAP上取得了显著的未加权准确率提升，特别是在类别不平衡的情感识别中，伴随的轻微加权准确率权衡反映了双曲空间对少数类表示几何上的优先排序；此外，HyPASE在受限参数预算内实现了稳健的零样本跨数据集泛化。通过将适应过程植根于双曲几何，HyPASE为LALM微调提供了一条高效路径。

## Abstract
Large Audio-Language Models (LALMs) excel at general speech understanding; however, adapting them to fine-grained tasks like Speech Emotion Recognition (SER) remains a significant bottleneck. Current Parameter-Efficient Fine-Tuning (PEFT) methods typically operate in flat Euclidean space, and this geometry fails to capture the multi-granularity nature of emotion cues, which range from low-level prosody to high-level semantics. To address this, we propose HyPASE, a hyperbolic PEFT framework for LALM-based SER. HyPASE leverages the Poincare ball model, using the hyperbolic radius as an explicit proxy for representational granularity. The framework consists of two core components: a Hyperbolic Geometric Adapter (HGA) for layer-adaptive weight modulation, and an Emotion-aware Multi-capacity Cross-modal Aggregator (EMCA) that compresses multi-scale features into compact audio prefixes. Empirical results on standard benchmarks show that HyPASE outperforms Euclidean PEFT baselines across all metrics on MELD and achieves a notable Unweighted Accuracy gain on IEMOCAP, particularly in class-imbalanced emotion recognition, with the accompanying slight Weighted Accuracy trade-off reflecting hyperbolic space's geometric prioritization of minority-class representations; furthermore, HyPASE achieves robust zero-shot cross-dataset generalization within a constrained parameter budget. By grounding the adaptation process in hyperbolic geometry, HyPASE offers a highly efficient path for LALM fine-tuning.

## 1. 核心问题与整体含义（研究动机与背景）

- **核心问题**：大型音频语言模型（LALMs）虽然在通用语音理解上表现优异，但在适应**细粒度任务（如语音情感识别 SER）** 时存在显著瓶颈。现有参数高效微调（PEFT）方法（如 LoRA、Adapter、Prefix Tuning）均在**平坦的欧氏空间**中操作，无法捕捉情感线索的**多粒度嵌套结构**（从低层韵律声学特征到高层语义抽象）。
- **关键观察**：作者通过对 Qwen2-Audio 编码器各层表示进行 **Gromov δ-双曲性分析**，发现音频表示的几何结构本质上是**树状/类双曲**的（δ 值远低于随机高斯基线，最低比值仅 0.014），而非平坦的欧氏结构。这为将适配过程引入双曲空间提供了直接经验依据。
- **核心洞察**：双曲空间（庞加莱球）具有随半径指数增长的体积，天然适配层级结构——**小半径承载粗粒度共性模式，大半径承载细粒度判别性语义**，恰好对应 LALM 编码器中从浅层到深层的表征抽象递进。
- **研究空白**：双曲几何已在视觉-语言模型（HyperET）和多模态安全对齐（HySAC）中得到初步验证，但从未被引入 LALM 的参数适配过程。HyPASE 填补了这一空白。

## 2. 提出的方法论

### 2.1 整体框架

- 音频编码器和语言解码器均**冻结**，仅训练 HGA、EMCA、原生多模态投影器以及残差适配器，总可训练参数仅占 Qwen2-Audio-7B 的约 **0.12%**。
- 模型流程：音频输入 →（HGA 增强的冻结编码器）→ 帧级表示 → EMCA 压缩为 K 个音频前缀 token → 多模态投影 → 与指令 prompt 的文本嵌入拼接 → 冻结 LLM 输出情感标签。

### 2.2 核心组件一：双曲几何适配器（HGA）

- **定位**：作用于音频编码器**权重空间**，实现层自适应的双曲半径调制（而非逐样本推理开销）。
- **数学基础**：将冻结权重行经指数映射 `exp_{D,c}(·)` 嵌入庞加莱球，通过 **Möbius 标量乘法**调整半径后再经对数映射 `log_{D,c}(·)` 恢复欧氏权重。核心定理（Thm 3.1）证明了标量双曲半径缩放等价于 Möbius 标量乘法，使得标量可通过标准 AdamW 优化。
- **关键设计**：将单一标量推广为**对角调制矩阵** `W_s = diag(s^(ℓ))`，每层每维度独立学习径向缩放因子（Proposition 3.2 给出等效行级半径缩放公式）。对角参数化的几何合理性在于——粒度控制需要**径向缩放而非旋转**：缩放保持预训练权重的相对角度结构（语义关系），仅改变粒度层级；旋转则会破坏注意力语义。
- **非对称注入**：仅替换自注意力层的 **Q 和 V 投影**，保持 K 投影冻结。理由：K 决定注意力锚点（冻结以保持预训练注意力模式），Q/V 决定查询和提取的粒度层级。
- **实现高效性**：完整的 exp→Möbius 缩放→log 流程可简化为对冻结权重行在切空间的**逐元素缩放**（Corollary A.5），仅需若干元素级操作和 tanh/artanh 调用，无额外大矩阵存储。

### 2.3 核心组件二：情感感知多容量跨模态聚合器（EMCA）

- **定位**：轻量级话语级读出模块，将 HGA 增强后的帧级表示压缩为 LLM 可消费的紧凑音频前缀。
- **五步流程**：
  1. **任务条件门控**：对音频和指令 prompt 分别做全局平均池化，通过 Hadamard 乘积实现门控（`ã = ā ⊙ (W_text t̄ + b_text)`），抑制与情感无关的声学噪声（信道噪声、说话人特征等），参数仅为交叉注意力的约 1/3。
  2. **三分支多容量压缩**：三个 MLP 分支分别以 1/8、1/16、1/32 的瓶颈比率提取互补粒度的情感表征。
  3. **输入自适应路由**：通过 softmax(W_route ã) 动态计算三个分支的融合权重。
  4. **爱因斯坦中点双曲融合**：三分支输出映射到庞加莱球，通过 Einstein midpoint 融合。几何特性：靠近球边界的点（更细粒度的判别性语义）其 Lorentz 因子更大，**自动获得更高的融合权重**——这是欧氏平均不具备的几何原生加权机制。
  5. **前缀生成**：融合向量经投影和前缀生成器 Π 扩展为 K 个音频前缀 token。

### 2.4 训练目标

- 复合损失：`L = L_CE + λ_hyp · L_hyp + λ_radius · L_radius`（默认 λ_hyp = 0.1，λ_radius = 0.01）。
- **L_hyp（双曲原型损失）**：在 EMCA 融合点与可学习类别原型之间施加基于**测地距离**的交叉熵损失（温度 τ = 0.07），将径向结构锚定到情感语义。
- **L_radius（半径排序损失）**：通过边际排序损失强制三分支的半径保持高→低容量的单调顺序，建立分支分离先验。消融显示两个损失**缺一不可**。

## 6. 主要结论与发现

- **MELD 全面领先**：在 0.12% 参数预算下，HyPASE 在 UA、WA、F1 三个指标上均超越 LoRA 和 Adapter，其中 F1 增益最大（+5.48 pp 相对 LoRA）。
- **IEMOCAP 上体现少数类优先特性**：UA 较 LoRA 提升 +3.23 pp（78.90 → 82.13），而 WA 微降 −1.52 pp。这是双曲空间几何特性的**主动结果**——指数级体积增长天然为少数类分配更多表征容量，而非模型退化。
- **零样本泛化能力强**：在 RAVDESS、SAVEE、IEMOCAP 三个目标域上均超过所有非 LALM 基线和 Qwen2-Audio 零样本基线，SAVEE 上提升高达 +35.8 pp（30.83 → 66.67 WA）。
- **逐类分析揭示再平衡效应**：MELD 上 7 类中 6 类 F1 提升，neutral（+75.9 pp）和 joy（+43.1 pp）提升最大；surprise 类 F1 下降（−19.3 pp）系零样本基线过度预测该类所致，其 recall 仍保持 61.31%，属预测分布再平衡而非能力损失。
- **几何验证充分**：音频编码器各层表示均呈现远超随机基线的类双曲结构；HGA 学到的缩放因子呈清晰的层间梯度——浅层收缩（粗粒度）、深层扩张（细粒度），与 encoder 层级抽象一致。

## 7. 优点

- **动机扎实**：以 Gromov δ 双曲性测量为直接经验依据，而非仅为使用双曲空间而使用，方法论闭环完整。
- **几何设计精巧**：
  - HGA 的对角参数化具备严格的几何充分性论证（只需径向缩放、无需旋转）；
  - Q/V 非对称注入设计意图明确（保持注意力锚点，调制查询提取粒度）；
  - Einstein midpoint 的 Lorentz 因子加权天然偏好边界近端（细粒度语义）点，属几何固有的优先级机制。
- **参数效率卓越**：HGA 本身仅需每层 2d_a 个缩放参数（全模型约 1.06M），完整框架约 0.12% 参数即可超越 10.49M 参数的欧氏 PEFT 基线。
- **理论完备**：提供完整定理证明（Thm 3.1、Proposition 3.2、Lemma A.1），并给出实现层面的数值稳定性处理（artanh clamp + 自定义反向传播）。
- **消融设计严谨**：逐层剥离几何贡献（M1 vs. G2）、监督贡献（L0→L1→L2→full）、结构贡献（G1/G3），清晰归因性能来源。
- **隐私/效率友好**：不使用 ASR 转录文本，纯音频输入，避免跨模态隐私泄漏风险。

## 8. 不足与局限

- **骨干泛化性未验证**：所有实验仅在 Qwen2-Audio-7B 单一骨干上进行，未验证框架在其他 LALM（如 SALMONN、Qwen2-Audio 其他规模）上的可迁移性，结论的外部效度受限。
- **语言与语料覆盖有限**：基准均为英语（IEMOCAP、MELD、RAVDESS、SAVEE），未验证跨语言情感识别效果；情感类别体系也较有限（4 类和 7 类）。
- **IEMOCAP 上的 WA 权衡**：虽然 UA 提升被解释为少数类优先的主动几何选择，但 WA 的 −1.52 pp 下降在需要总体准确率的实际部署场景中可能构成阻碍，论文未提供缓解方案。
