## 摘要
功能性磁共振成像（fMRI）是研究大脑的广泛使用的技术。近年来，利用图神经网络（GNN）分析大脑功能连接的方法在脑疾病（如阿尔茨海默病，AD）分类中显示出巨大潜力。然而，这些方法通常假设所有受试者具有预设数量的功能模块，这忽略了受试者间的变异性。此外，发现的模块很少被直接用于指导学习到的连接模式。为了解决这些问题，我们提出了一种元概率池化GNN（MPP-GNN）。我们将模型的任务构建为耦合的双层优化，该优化通过层次化执行自适应图划分来发现受试者特定的模块，然后使用发现的脑模块作为显式先验来指导边的细化和表示学习。我们在两个公共数据集上验证了MPP-GNN用于AD分类，在两个数据集上都实现了与已有基线相比最高的AUC。此外，我们的分析表明，MPP-GNN与Yeo脑图谱定义的标准功能网络组织显示出显著的对齐性，并揭示了AD的网络级去分化模式。

## Abstract
Functional magnetic resonance imaging (fMRI) is a widely used technique for studying the brain. Recent methods that utilize graph neural networks (GNNs) for analysis of brain functional connectivity have shown great potential for the classification of brain disorders, such as Alzheimer's disease (AD). However, these methods often assume a preset number of functional modules across all subjects, which overlooks inter-subject variability. In addition, the discovered modules are rarely used to directly guide the learned connectivity patterns. Here, to address these issues, we propose a Meta Probabilistic Pooling GNN (MPP-GNN). We frame the model's task as a coupled, bilevel optimization that performs adaptive graph partitioning hierarchically to discover subject-specific modules and then uses the discovered brain modules as an explicit prior to guide edge refinement and representation learning. We validate MPP-GNN on two public datasets for AD classification, achieving the highest AUC in comparison to established baselines for both datasets. Furthermore, our analysis demonstrates that MPP-GNN shows significant alignment with the canonical functional-network organization defined by the Yeo brain atlas and reveals a network-level dedifferentiation pattern for AD.

### 一、论文的核心问题与整体含义（研究动机和背景）

- **背景与问题**：阿尔茨海默病（AD）是一种常见的神经退行性疾病，fMRI 作为一种无创技术，可用于构建大脑功能连接（FC）网络，进而辅助 AD 的早期诊断。近年来，图神经网络（GNN）被广泛用于分析脑网络图，并在脑疾病分类中展现出良好潜力。
- **核心矛盾（三个典型挑战）**：
  1. **噪声问题**：BOLD 信号衍生的 FC 矩阵本质上是含噪的，生理伪影和扫描时长等因素带来个体内与个体间的大幅变异。
  2. **模块异质性问题**：大脑高度模块化，且 AD 与模块组织破坏有关；但许多 GNN 社区检测方法预设了所有受试者共享的固定聚类容量，无法适应个体的特异性脑组织。
  3. **可解释性问题**：常见的后验可解释方法（如显著性图、替代解释）在不同算法之间一致性差，对模型内在机制解释有限。
- **核心观点**：上述挑战相互关联——社区结构可以指导边的细化（区分社区内/社区间连接），而细化后的边与学习到的表示又能反过来改进划分策略。因此，**应将社区发现、边去噪、表示学习纳入一个端到端框架内联合优化**，而不是作为独立的预处理或后验步骤。

### 二、论文提出的方法论：核心思想与技术细节

**整体框架**：MPP-GNN 采用**耦合双层优化**（bilevel optimization）框架：
- **外层（outer level）**：学习一个自适应的图划分策略（通过元权重 W_meta 的分布参数化），以最大化模型在验证集上的性能（如 AUC）。
- **内层（inner level）** ：基于划分结果，联合优化边细化与节点表示学习（GCN），最小化分类损失。

**关键模块与流程**：

1. **元权重参数化与 SBO 优化**：
   - 元权重 W_meta 服从多变量高斯分布 N(μ, σ²_meta I)，将节点特征 X(0) 投影到元特征空间 Z_meta。
   - 采用平滑变分优化（SBO，Smoothing-Based Optimization）策略，通过样本加权更新 μ 和 σ_meta，从而将离散的图划分问题连续化，使外层优化成为可行（不需要梯度，仅需点值评分）。
   - 外层更新公式为：μ^(t+1) = Σ F^(t,s) W^(t,s)_meta / Σ F^(t,s)，σ 类似更新，直至 σ_meta 低于阈值收敛。

2. **AP-HPM（基于亲和传播的层次池化模块）**：
   - 相似度矩阵 S(1) 结合元特征距离（D_Z）、度差异（D_deg）和最短路径距离（D_sp）：S(1) = exp(−D_Z − λ_deg D_deg − λ_sp D_sp)。
   - 使用 Affinity Propagation（AP）算法进行层次化图聚类，无需预设聚类数量，自适应于每个个体的图结构复杂度。
   - 通过平均池化聚合节点特征，通过平均层间边权重构造稀疏的社区间连接图；逐层递归得到多分辨率层次结构（ROI→网络→系统）。

3. **PERM（概率边细化模块）**：
   - 为每条边构造三个可解释特征：①相似度矩阵项 S(l)；②同社区指示 C(l)（+1 同社区，−1 不同社区）；③当前节点特征间的余弦相似度 R(l)。
   - 通过 logistic 函数计算边保留概率：P(l) = σ(λ_1 S(l) + λ_2 C(l) + λ_3 R(l) + λ_4)，其中 λ learnable。
   - 通过松弛伯努利采样（relaxed Bernoulli mask）将概率转换为近离散掩码，保留梯度流，同时起到结构数据增强作用，获得细化后的邻接矩阵 Â(l) = Ã(l) ⊙ M(l)。

4. **内层基模型与损失函数**：
   - 内层使用三层 GCN（维度 64→32→16），配合 GraphNorm 和 GELU 激活函数。
   - 损失函数包含分类损失（focal loss，缓解类别不均衡）与边熵正则项 L_edge（鼓励 P(l) 离开 0.5 模糊区，趋于二值化判断）：L = L_cls + λ_edge L_edge。

### 三、实验设计：数据集、基准与对比方法

### 七、优点：方法与实验设计的亮点

- **方法创新**：将社区发现与图表示学习耦合成双层优化问题，克服了传统“先社区发现、后下游任务”的两阶段割裂；通过 SBO 巧妙处理离散划分的不可微问题。
- **自适应结构**：AP 聚类的使用取消了预设聚类数量的限制，能适应个体间的大脑组织差异（subject-adaptive）；这正是脑网络分析中常常被忽略的先验。
- **可解释性内建**：PERM 的可解释门控和 AP-HPM 的显式社区分配本身即可作为分析对象，避免了后验解释的不稳定性问题。
- **验证充分与临床一致性**：不仅报告分类指标，还深入分析模块结构与疾病相关的生物学模式（去分化、颞极受累），将模型发现与既有医学知识联系起来，增强了可信度。
