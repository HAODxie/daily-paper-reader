## 摘要
尽管神经影像方法取得了巨大成功，但使大规模、高维数据集为AI/ML应用做好准备仍是一个关键的操作瓶颈。传统工作流程需要在元数据整理、流水线执行、后期质量控制和数据管理方面投入大量人工努力，这一负担不成比例地将人力和计算基础设施有限的实验室排除在外。为了解决这一现实障碍，迫切需要可扩展、成本效益高的计算平台，使先进的神经影像分析民主化，并加速心理健康和临床转化方面的发现。利用多智能体LLM的突破，我们推出了CyberNeuro，这是一个配备定制本地LLM模型（'WandaMind'）的智能体工作台，用于自动化神经影像和健康数据分析。通过四个专用智能体（规划器、验证器、调度器和报告器）通过安全的MCP桥接和固定执行层进行通信，CyberNeuro使研究人员能够使用自然语言执行复杂工作流程，同时保持临床级数据隐私。在公开的NeuroBench套件上，CyberNeuro将保留领域准确率从基线模型的40%提高到69%。除了自动化指标外，该平台还集成了人在回路验证面板，以确保严格的生物医学质量控制。在相同的端到端10批次队列工作流程套件中，与Neuroclaw相比，本地WandaMind配置完成了所有任务，估计聚合令牌数量约为WandaMind的10.6%和云提供商的61.7%。该平台及其生产就绪模块可在https://wanda-cyberbench.com获取。

## Abstract
Despite tremendous success in neuroimaging methodology, making large-scale, high-dimensional datasets ready for AI/ML applications remains a critical operational bottleneck. Conventional workflows require extensive manual effort across metadata curation, pipeline execution, post-processing quality control, and data management, a burden that disproportionately excludes laboratories with limited manpower and computational infrastructure. To address this real-world barrier, there is an urgent need for scalable, cost-effective computational platforms that democratize advanced neuroimaging analytics and accelerate discoveries in mental health and clinical translation. Capitalizing on multi-agent LLM breakthroughs, we introduce CyberNeuro, an agentic workbench with a tailored local LLM-model ('WandaMind') for automated neuroimaging and health-data analysis. Driven by four dedicated agents (Planner, Validator, Dispatcher, and Reporter) communicating via a secure MCP bridge and a pinned execution layer, CyberNeuro enables researchers to execute complex workflows using natural language while maintaining clinical-grade data privacy. On the public NeuroBench suite, CyberNeuro increases held-out domain accuracy from 40% to 69% over the baseline model. Beyond automated metrics, the platform integrates a human-in-the-loop verification panel to ensure rigorous biomedical quality control. Across the same end-to-end 10-batch cohort workflow suite, the local WandaMind configuration completed all tasks with an estimated aggregate token count of about 10.6% using WandaMind and 61.7% using cloud providers of token usage, compared to Neuroclaw, respectively. The platform and its production-ready modules are available at https://wanda-cyberbench.com.

### 1. 核心问题与整体含义

- **背景与动机**：神经影像分析方法已取得巨大成功，但让大规模、高维数据集为 AI/ML 应用做好准备仍是关键操作瓶颈。传统工作流需要在元数据整理、流水线执行、事后质量控制和数据管理上投入大量人工劳动，这一负担不成比例地将人力和计算资源有限的实验室排除在外。
- **核心问题**：如何构建一个**可扩展、成本效益高、且尊重数据隐私**的计算平台，使先进神经影像分析能力民主化，加速心理健康与临床转化研究。
- **整体含义**：CyberNeuro 以**本地优先（local-first）+ 多智能体 LLM 编排**的方式回答上述问题——让研究人员用自然语言驱动复杂神经影像分析流程，同时保持临床级数据隐私（零出站网络流量），从而将原先需 1–2 个月的助理训练周期压缩至约一周，并实现严格可复现性和全面溯源。

### 2. 方法论

- **系统架构（三层）**：
  - **交互层**：自然语言聊天请求、技能中心（Skill Hub，含 30+ 神经影像处理与可视化技能）、交互式协同可视化面板。
  - **编排层（LLM）**：由本地 7B 模型 **WandaMind** 驱动，通过**安全 MCP 桥**连接四个专用智能体——**Planner（规划器）、Validator（验证器）、Dispatcher（调度器）、Reporter（报告器）**。
  - **技能进化层**：内置流程将元技能草稿通过多阶段验证门（schema → install → execution → artifacts → human）固化为稳健的冻结技能包；Memory Pill 保留用户偏好与跨平台配置。

- **四阶段混合编排**：
  - **Planner**：LLM 驱动，从 SKILL.md 描述和类型化契约中检索候选技能，生成任务 DAG（节点含技能、输入、参数、预期输出、运行时、权限、恢复方案）。
  - **Validator**：**确定性**验证，分三处执行——契约验证（技能名、参数模式、输入类型、输出位置）、策略与运行时验证（规范路径、权限、覆盖风险、网络要求）、执行后验证（退出状态、期望文件、可解析性、领域不变量）。零退出码但无真实产物归类为 `failed_artifact_validation`。
  - **Dispatcher**：仅执行验证过的节点，通过工具注册表强制运行时/权限决策，记录日志与资源使用。
  - **Reporter**：汇总已验证的产物、HTML 摘要、日志和收据，将兼容输出暴露给可视化/QC 面板；面板中的编辑成为新溯源节点而非静默修改原结果。
  - 架构原则可概括为 **“LLM 路由、工具确定性”**：LLM 负责提出路由方案，确定性工具完成科学计算，验证层判定结果是否对应真实合规产物。

- **WandaMind 模型**：
  - 基础模型：Qwen2.5-7B-Instruct；采用 **QLoRA** 微调（4-bit NF4 冻结基座权重，rank=32，α=64，dropout=0.05，学习率 3 epochs），仅 8070 万可训练参数（占总参数 1.06%），**仅对 assistant 响应计算损失（response-only supervision）**。
  - 训练数据：315 条教师生成轨迹 + 306 条规则扩展 + 101 条定向困难案例 = 核心池 701/722 条轨迹；经 schema 验证器和 Jaccard 去污染（阈值 ≥0.55 剔除）过滤，41 条候选被拒。
  - 三轮训练：①监督初始化 → ②仅动作（ACT-only）增强 → ③对抗性加固（区分 act / refuse / search 决策边界）。
  - 部署：LoRA 适配器合并后转 GGUF、Q4_K_M 量化。

- **隐私与安全**：
  - 仅 Windows 桌面部署，主机与 WSL 通过本地端点通信，默认无出站网络。
  - 威胁模型覆盖三种风险：LLM 提出策略外工具调用、注册工具接收不安全路径/参数、任务尝试未授权出站连接；通过工作区隔离、路径规范化、能力白名单、类型化技能契约、权限检查、执行日志和产物验证来缓解。
  - 每次运行生成结构化**收据（receipt）**：包含请求哈希、工具版本、容器摘要、解析命令、输入输出哈希、退出码、验证结果、网络模式、用户批准和恢复动作。

### 7. 优点

- **架构设计的严谨性**：将 LLM 规划与确定性契约/权限/运行时/工件验证分离，杜绝“LLM 声称成功即成功”的问题；故障注入实验证明产物验证器是无人值守执行可信度的关键控制。
- **隐私保护的落地性**：默认无出站网络 + 进程级断网验证 + 负控测试，而非仅宣称隐私，提供了可复现的证据链。
- **资源效率突出**：7B 本地模型（1.06% 可训练参数）即达到优于 27B 模型的决策质量，且令牌消耗比 NeuroClaw 降低近 9.3 倍（每 NIfTI），显著降低运营成本。
- **工程完成度高**：30+ 技能覆盖 sMRI/fMRI/dMRI/网络/可视化全链路；收据（receipt）含 17 个字段；可视化面板支持同步、编辑、截图与可复现重放；技能进化机制（Meta-skill）具备严格验证门。[^1]
- **评估分层清晰**：模型级（能力）与系统级（工作流、隐私）分开评测，避免以模型分数代替端到端性能；对比了本地 vs 云后端、CyberNeuro vs NeuroClaw 两个维度，结论有区分度。

### 8. 不足与局限

- **技能覆盖不如基线系统**：CyberNeuro 有 30+ 技能，NeuroClaw 有 85 技能和更广的数据集覆盖。
- **本地模型能力上限**：7B 模型在长上下文推理方面弱于前沿云模型，限制了单次规划请求的复杂度。

- **网络行为结论有边界**：监控条件的 netstat 数据无法在进程级归因；仅验证“加固版在测试配置和时间窗口”的零出站行为，不构成正式隐私保证或气隙合规证明。
- **客观限制**：部分功能未发布——半自动 QC 技能仍开发中、面板编辑工具仅覆盖最常见操作、无需外部连接的初始安装会下载权重与 WSL 包（安装阶段并非完全离线）。
- **部署平台单一**：仅支持 Windows 桌面，无 macOS/Linux 原生版、无云模型选项或服务器模式，限制了跨机构采用范围。
