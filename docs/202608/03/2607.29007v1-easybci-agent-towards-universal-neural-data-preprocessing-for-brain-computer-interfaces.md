## 摘要
脑机接口将神经活动转化为设备指令，但其性能依赖于预处理，而预处理目前仍依赖人工、需要专家经验且可重复性差。大语言模型智能体可以自动化科学编码，但现有系统缺乏神经预处理所需的模态覆盖、原始数据隔离、经验积累和领域监督。我们引入了EasyBCI，一个两阶段的LLM智能体，可为六种信号类型规划并执行预处理流程。规划智能体将每次记录概况为仅文本的数据指纹，该指纹从不向模型暴露原始数据，并选择基于文献的操作序列。执行智能体生成、运行并自我修正代码，直至满足质量标准，同时一个质量门控的经验系统将验证过的策略保留为可复用技能。领域专家在两个决策门处介入，在未检测到的错误可能使下游分析失效的地方保留人类判断。在使用固定线性分类器的EEG评估中，所有五个EasyBCI骨干网络都比手动流程保留了更多任务相关的可分性。在同一骨干网络比较下，EasyBCI在五种配置中的四种上，两种标签方案均优于通用编码智能体。EasyBCI可扩展到另外五种模态，采样率跨越近三个数量级，并生成具有记录决策来源的完整可复现流程。这些结果表明，特定领域的编排可以使缺乏专门专业知识的实验室也能进行可审计的预处理，并展示了适用于其他科学领域AI智能体的设计原则。

## Abstract
Brain-computer interfaces translate neural activity into device commands, yet their performance hinges on preprocessing that remains manual, expert-dependent and poorly reproducible. Large language model agents can automate scientific coding, but existing systems lack the modality coverage, raw-data isolation, experience accumulation and domain oversight that neural preprocessing requires. We introduce EasyBCI, a two-phase LLM agent that plans and executes preprocessing pipelines for six signal types. A Plan Agent profiles each recording into a text-only Data Fingerprint that never exposes raw data to the model and selects a literature-grounded operator sequence. An Execution Agent generates, runs and self-corrects code until quality criteria are met, while a quality-gated experience system retains validated strategies as reusable skills. A domain expert intervenes at two decision gates, retaining human judgement where undetected error can invalidate downstream analyses. Evaluation on EEG with a fixed linear classifier shows that all five EasyBCI backbones preserve more task-relevant separability than the manual pipeline. Under same-backbone comparison, EasyBCI outperforms general-purpose coding agents on both label schemes for four of five configurations. EasyBCI extends to five additional modalities spanning nearly three orders of magnitude in sampling rate, producing complete reproducible pipelines with recorded decision provenance. These results indicate that domain-specific orchestration can bring auditable preprocessing within reach of laboratories lacking dedicated expertise, illustrating design principles applicable to AI agents in other scientific domains.

# 论文详细总结：EasyBCI Agent

## 1. 核心问题与整体含义（研究动机与背景）

- **研究动机**：脑机接口（BCI）将神经活动转化为设备指令，其性能高度依赖原始信号的预处理流程。然而，当前预处理存在三大痛点：
  - **人工依赖强**：预处理参数选择依赖领域专家，手工操作占主导；
  - **可复现性差**：不同实验室对同一数据采用不同预处理流程，结论可能显著分歧（甚至同一数据、同一分类器，仅改变预处理即可使试次级预测翻转高达42%）；
  - **模态覆盖不足**：EEG、MEG、sEEG、ECoG、fNIRS、Spikes 六种模态各有不同的信号物理机制、伪影类型和处理逻辑，单一专家难以全覆盖，且现有工具均无法自动化选择预处理决策。
- **现有方案不足**：
  - 信号处理库（MNE-Python、EEGLAB 等）只提供操作算子，无自动决策层；
  - 已有 LLM 代理（EEGAgent、EEG-AI 等）仅覆盖 EEG 单一模态；
  - 通用编码代理（Claude Code、Codex）缺乏 BCI 特定先验，参数选择不基于当前记录信号特征。
- **核心主张**：构建一个同时具备「六模态覆盖 + 原始数据隔离 + 经验积累 + 领域专家监督」四要素的自动化预处理系统（EasyBCI），使预处理从"实验变量"变为可审计、可复现的标准化环节，并为其他科学领域的 AI 代理提供设计原则。

## 2. 方法论：核心思想、关键技术细节

### 2.1 总体架构（两阶段 LLM 代理）

- **Phase 1 — Plan Agent（规划代理）**：
  - 用户仅提供数据路径 + 自然语言预处理目标；
  - 先通过 **Auto-Inspect** 对原始记录进行自动检查，生成文本形式的 **Data Fingerprint（数据指纹）**；
  - 再通过 **Reasoning & Planning** 结合数据指纹与网络检索的文献证据，输出带逐步骤依据的 **Pipeline Plan（流水线计划）**。
- **Phase 2 — Execution Agent（执行代理）**：
  - 逐步骤执行批准后的计划，进入 **Code → Execute → Reflect** 内循环；
  - 每步最多自动修复 3 次，失败则暂停等待专家介入；
  - 输出可独立运行的 mini-repository（含代码、计划、推理日志、QC 报告、AI-ready 数据）。

### 2.2 关键技术细节

- **数据指纹（Data Fingerprint）**：将原始信号 x 压缩为文本摘要 φ(x) = (格式、模态、通道数、采样率、时长、频谱概要、通道统计、伪影指标、事件结构)，原始数值数组永不进入 LLM 上下文，token 成本降低约三个数量级。
- **算子契约（Operator Contract）**：每个算子接收统一状态字典 D = (X, c, f_s, T, μ)，须满足三条规则：不可原地修改输入、失败须抛出类型化异常、禁止网络/文件 I/O（除非显式允许）；由静态 AST linter 在生成时强制检查。
- **质量加权技能检索（Quality-weighted Skill Retrieval）**：
  - 技能库 S 记录模态、范式、通道数、采样率、时长、步骤列表、目标及内联算子实现；
  - 匹配分数 sim(o, φ; s_j) = Σ_d w_d · f_d(...)，模态和目标是硬过滤器（不匹配即零分），其余四个软轴加权；分数再乘以质量权重 λ(s_j)（基于历史 QC 通过率 ρ）；
  - 每次取 top-3 技能注入 LLM 提示词；
  - 技能生命周期：new → active → deprecated（通过率低于 40% 且使用至少 5 次后自动弃用）。
- **源数据保护（Source Data Guard）**：三层机制保障原始数据不出盘、不被修改：
  1. 抽象层：LLM 只接收文本指纹；
  2. 写阻止层：保护路径上的任何写入/删除/重命名都会中止当前步骤；
  3. 完整性层：每次执行前后校验文件大小与修改时间，不匹配即中止。
- **专家在环（Expert-in-the-Agent-Loop）**：
  - 门 1（计划确认门）：专家可确认、修改或中止计划，决策被记录；
  - 门 2（修复耗尽门）：自动修复 3 次失败后，专家可提供修正提示、跳过该步或中止整个运行。
- **可复现性机制**：
  - 自动插入确定性种子（锁定 Python hash seed、random、NumPy）；
  - 生成代码禁止导入 EasyBCI 框架命名空间（仅依赖 mne、numpy、scipy、scikit-learn、matplotlib 五个标准包）；
  - 输出 mini-repository 记录源文件 SHA-256 哈希。
- **模态覆盖**：两层设计——原生加载器注册表（EEG、MEG、sEEG、ECoG、Spikes）+ 技能文件接口（fNIRS 和厂商特定 spike 格式）。新增模态只需提供符合规范的 reader 和技能描述文件。

## 3. 实验设计：数据集 / 场景、基准与对比方法

### 3.1 主要定量实验（EEG）

- **数据集**：自采 64 通道运动想象 EEG（Curry 格式），1000 Hz，2 个 session（37.6 min + 24.3 min），每 session 40 试次，含 2 类动作标签（pick/place，二分类）和 4 类对象标签（apple/basket/bowl/plate，四分类）。

- **对比方法**：
  - Raw（无预处理）、Manual（人工文献基准管线）；

## 6. 主要结论与发现

- **EasyBCI 全面优于 Manual 管线**：5 个骨干在二分类（61.75%~78.25% vs 55.25%）和四分类（36.65%~46.65% vs 25.25%）上均高于人工设计管线；Raw 基线接近随机水平（49.95% / 23.75%），证明预处理必要性。
- **同骨干对比中 EasyBCI 胜出**：Opus 4.8 上 66.85% vs 64.00%（二分类）、44.70% vs 32.50%（四分类）；GPT-5.5 上 65.35% vs 63.29%（二分类）、40.65% vs 35.54%（四分类）——领域特定编排显著优于通用代理。
- **架构贡献大于模型差异**：四分类任务上最弱骨干 GPT-4o（36.65%）仍超过两个通用代理，说明 EasyBCI 的领域约束、规划机制和质量反馈比骨干模型本身更重要。
- **跨模态泛化成功**：同一框架在 6 种模态上均产出 QC-passing 管线，PSD SNR 提升 1.4×~11.1×，无 NaN 引入。
- **可复现性达成**：输出 mini-repository 可在无 EasyBCI 的环境下独立运行，含完整决策溯源（provenance）。

## 7. 优点

- **隐私友好架构**：原始信号永不进入 LLM 上下文，隐私审查简化为检查文本指纹，是"privacy-by-architecture"的良好示范；
- **算子契约 + 静态检查**：通过类型化 I/O 契约、不可变规则和 AST linter 从生成源头减少错误代码；
- **质量门控的经验机制**：只有通过 QC 的管线才入库，低通过率技能自动弃用，缓解了朴素技能积累导致的性能退化问题；
- **专家双门监督**：将人为干预精确定位在计划确认和修复耗尽两个高风险点，兼顾自动化与安全性；
- **固定分类器验证方法学**：CSP+LDA 作为可解释的质量探针，干净地隔离了预处理变量，方法可推广到其他模态；
- **多层可复现保障**：确定性种子、禁用框架依赖、源文件完整性校验、SHA-256 哈希记录，形成了完整的可复现闭环；
- **可扩展架构**：两层模态接入设计（原生加载器 + 技能文件）使得新增模态无需改动核心逻辑。

## 8. 不足与局限

- **下游耦合缺失**：预处理参数选择未显式考虑下游解码器性能；论文自身指出，将下游解码准确率纳入接受标准是未来方向；
- **QC 指标停留在信号层面**：尚未与临床诊断结局、患者人群差异等建立关联，临床适用性有待验证；
- **实时性不支持**：当前执行器是批处理模式，不满足实时闭环 BCI 的延迟约束；
- **定量评估范围有限**：EEG 实验仅单一数据集、单一任务类型（运动想象），且无显著性检验；多模态评估缺乏下游任务指标；
- **无正式消融实验**：无法从实验上证明各组件（技能检索、文献证据、专家门、数据保护）的独立贡献；
- **冷启动与长期稳定性未验证**：空技能库起步，技能库长期演化、联邦学习的实际效果缺少纵向实验；
- **潜在安全与部署风险**：论文承认多租户部署需容器级沙箱，当前单研究者场景中的三层保护是否足以应对恶意提示注入、未经授权的数据访问等安全问题尚未充分探讨；
- **外部依赖**：文献检索依赖可插拔搜索后端（默认 Exa）与 LLM API 服务，外部服务不稳定或审查可能影响系统可用性；
- **基线公平性问题**：Manual 管线设计者虽然遵循文献，但"固定不调参"的人为限制可能低估传统专家方法的真实水平，广义上存在基线优势偏向代理系统的风险。
