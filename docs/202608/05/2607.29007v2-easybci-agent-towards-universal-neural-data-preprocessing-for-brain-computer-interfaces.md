## 摘要
脑机接口将神经活动转换为设备指令，但其性能依赖于预处理，而预处理仍然需要手动操作、依赖专家且可重复性差。大型语言模型代理可以自动化科学编码，但现有系统缺乏神经预处理所需的模态覆盖、原始数据隔离、经验积累和领域监督。我们引入了EasyBCI，一个两阶段的LLM代理，为六种信号类型规划和执行预处理流程。计划代理将每次记录概况为仅文本的数据指纹，该指纹从不向模型暴露原始数据，并选择基于文献的操作序列。执行代理生成、运行和自动纠正代码，直到满足质量标准，而质量门控的经验系统将验证过的策略保留为可重用技能。领域专家在两个决策门处介入，在未检测到的错误可能使下游分析失效的地方保留人类判断。在使用固定线性分类器对EEG的评估中，所有五个EasyBCI主干都比手动流程保留了更多与任务相关的可分离性。在同一主干比较下，EasyBCI在四种配置中的两种标签方案上均优于通用编码代理。EasyBCI扩展到五种额外模态，采样率跨越近三个数量级，生成具有记录决策来源的完整可重现流程。这些结果表明，特定领域的编排可以使可审计预处理在没有专门专业知识的实验室中也能实现，展示了适用于其他科学领域AI代理的设计原则。

## Abstract
Brain-computer interfaces translate neural activity into device commands, yet their performance hinges on preprocessing that remains manual, expert-dependent and poorly reproducible. Large language model agents can automate scientific coding, but existing systems lack the modality coverage, raw-data isolation, experience accumulation and domain oversight that neural preprocessing requires. We introduce EasyBCI, a two-phase LLM agent that plans and executes preprocessing pipelines for six signal types. A Plan Agent profiles each recording into a text-only Data Fingerprint that never exposes raw data to the model and selects a literature-grounded operator sequence. An Execution Agent generates, runs and self-corrects code until quality criteria are met, while a quality-gated experience system retains validated strategies as reusable skills. A domain expert intervenes at two decision gates, retaining human judgement where undetected error can invalidate downstream analyses. Evaluation on EEG with a fixed linear classifier shows that all five EasyBCI backbones preserve more task-relevant separability than the manual pipeline. Under same-backbone comparison, EasyBCI outperforms general-purpose coding agents on both label schemes for four of five configurations. EasyBCI extends to five additional modalities spanning nearly three orders of magnitude in sampling rate, producing complete reproducible pipelines with recorded decision provenance. These results indicate that domain-specific orchestration can bring auditable preprocessing within reach of laboratories lacking dedicated expertise, illustrating design principles applicable to AI agents in other scientific domains.

## 1. 核心问题与研究动机

- **痛点**：脑机接口（BCI）的性能高度依赖原始神经信号的预处理，而预处理长期依赖领域专家手动完成，存在参数组合爆炸、跨实验室可复现性差、不同流程导致同一数据产生不同结论等问题（文中引用显示仅更换预处理流程即可翻转高达 42% 的 trial 级预测）。
- **现有工具不足**：传统信号处理库（MNE-Python、EEGLAB、FieldTrip 等）仅覆盖单一模态且无自动决策层；已有 EEG 专用 LLM agent（如 EEGAgent、EEG-AI）仅支持 EEG；通用编码 agent（Claude Code、Codex）缺乏 BCI 领域先验知识。
- **关键需求**：系统需同时满足四点——覆盖六种信号类型（EEG、MEG、sEEG、ECoG、fNIRS、spike）、隔离原始数据（神经信号含个人可识别生理特征）、保留验证过的策略并避免劣化、在关键决策点嵌入专家监督。现有系统均无法同时满足。
- **整体含义**：预处理不是简单的准备步骤，而是决定下游结论的实验变量。EasyBCI 试图通过领域特化的 LLM agent 编排，使不具专门预处理经验的实验室也能获得可审计、可复现的标准化流程。

## 2. 方法论：核心思想与技术细节

**核心思想**：两阶段 LLM agent 架构——“Plan Agent + Execution Agent”，通过“文本化数据指纹”隔离原始数据，以“质量门控技能库”实现经验积累，并在两个高风险决策点强制引入专家判断。

### 2.1 两阶段架构

- **Plan Agent**：
  - Stage 1（Auto-Inspect）：将原始信号 `x` 压缩为仅含摘要统计量的文本 Data Fingerprint `φ(x)`（式 1），包含格式、模态、通道数、采样率、频谱概要、通道统计、伪迹指标、事件结构等。原始数组从不进入 LLM 上下文。
  - Stage 2（Reasoning & Planning）：结合指纹与用户目标 `τ`，通过 Web 检索获取文献证据 `E`，输出带逐步依据的 Pipeline Plan `(o_k, g, θ, E, m, κ)`（式 2），每一步需通过算子词汇表校验。
- **Execution Agent**：对计划中的每一步执行“Code → Execute → Reflect”内循环：
  - **Code**：基于质量加权技能检索（QSR）生成符合 Operator Contract 的 Python 函数；
  - **Execute**：在沙箱子进程运行（含 `RLIMIT_AS` 地址空间限制、超时控制、Source Data Guard 完整性校验）；
  - **Reflect**：自动 QC 模块检查通道方差、频谱合理性、事件对齐、频带漂移等，通过则进入下一步，失败则经错误分类器选择修复策略，最多自动重试 3 次（另有独立的基础设施重试计数），耗尽后暂停交由专家。

### 2.2 关键机制

- **Operator Contract**（算子契约）：所有算子接受统一状态字典 `D=(X, c, f_s, T, μ)`，要求不可原地修改、失败必须抛出类型化错误、禁止未经允许的 I/O；生成时代码经静态 AST linter 检查。
- **Source Data Guard**（原始数据保护）：三层防护——抽象层仅传文本指纹；写阻断层保护源路径；完整性层在每步前后校验文件大小与修改时间。
- **Quality-weighted Skill Retrieval**（质量加权技能检索）：基于规则的多维加权匹配（式 3），模态和分析目标是硬过滤器，不匹配则得分为零；每个技能有质量权重 `λ(s_j)`（式 4），基于历史 QC 通过率，通过率低于 40%（≥5 次使用）自动弃用，负样本档案提供惩罚。
- **Expert-in-the-Agent-Loop**：双重专家门——计划确认门（确认/修改/中止）和修复耗尽门（提供提示、跳过或中止）；专家决策和编辑被记录用于溯源。
- **Progressive Skill Refinement & Federation**：仅当（QC 通过、目标类型合格、仓库契约完整、无重复签名）四个条件同时满足才保存为 Proven Skill；失败运行记录为负样本；支持跨实验室可选的签名联邦共享。
- **Computational Reproducibility**：生成代码自动插入确定性随机种子；禁止导入 EasyBCI 框架自身；输出自包含 mini-repository，可在无 agent 环境下用 `mne/numpy/scipy/scikit-learn/matplotlib` 独立复现；记录源文件 SHA-256。
- **Modality Coverage**：双层设计——原生加载器注册表（EEG/MEG/sEEG/ECoG/spike）和技能化接口（fNIRS、厂商 spike 格式），新增模态只需提供符合 `D` 的 reader 和技能描述符。

## 5. 主要结论与发现

- 在固定分类器探针下，**所有五种 EasyBCI 骨干的双标签方案准确率均高于 Manual 管线**，其中 DeepSeek-V4-Pro 在二分类达 78.25%（比 Manual 高 23 个百分点），四分类达 46.65%（比 Manual 高 21.4 个百分点）。
- **同骨干对比**：EasyBCI（Opus 4.8）66.85% vs. Claude Code 64.00%（二分类）、44.70% vs. 32.50%（四分类）；EasyBCI（GPT-5.5）65.35% vs. Codex 63.29%（二分类）、40.65% vs. 35.54%（四分类）。四分类上所有 EasyBCI 骨干均超过两个通用 agent，二分类上 4/5 超过。
- **架构比骨干模型更重要**：在四分类任务上，最弱 EasyBCI 骨干（GPT-4o，36.65%）仍超过两个最强通用 agent，说明领域约束、规划与质量反馈的贡献大于模型能力差异。

- **输出完整可审计**：生成的 mini-repository 包含独立运行代码、逐步骤科学推理文档、文献证据、QC 报告与源文件哈希，使预处理决策可被专家完整审计。

## 6. 方法/实验设计的亮点

- **隐私与效率的架构性解决**：Data Fingerprint 将原始信号替换为文本摘要，不但降低 token 成本约三个数量级，还从架构上保证原始数据永不进入 LLM 上下文，隐私审查退化为检查文本指纹。
- **质量门控的技能生命周期**：技能仅在通过神经生理学质量门后进入库，并通过历史通过率动态调整检索权重、自动弃用退化技能，回应了“简单积累会损害性能”的已知问题。
- **专家干预定位精准**：只在“计划确认”和“修复耗尽”两个最高风险点引入人工，兼顾自动化的效率与安全，且专家操作被作为溯源信息记录。
- **验证协议隔离变量**：固定 CSP+LDA 探针使“预处理”成为唯一实验变量，避免了分类器能力掩盖预处理差异的常见偏差。
- **可复现性设计扎实**：确定性种子、禁止导入框架本身、源文件完整性哈希、独立 `requirements.txt`，使输出可在无 agent 环境下复现，对科学可重复性意义重大。

## 7. 不足与局限

- **预处理与下游解码脱耦**：参数选择未显式使用下游解码器性能作为验收标准（仅信号级 QC），尽管文中承认预处理与解码在实际中是耦合的。
- **QC 指标局限**：自动质量指标仅信号级（方差、PSD SNR、NaN 比例等），未与临床结局或诊断效能建立关联。
- **定量验证覆盖窄**：核心定量实验仅一个 64 通道 EEG 数据集；多模态案例（sEEG、MEG、fNIRS、ECoG）仅有定性 QC，没有报告下游分类精度，无法量化这些模态上的实际增益。
- **冷启动模式限制**：所有主实验从空技能库开始，未考察技能积累与自动弃用机制在长期、多轮运行中的实际改善效果。
- **实时性缺失**：执行器面向批量数据，无法满足实时闭环 BCI 的延迟约束。
- **计算成本未透明**：未报告每次运行的 LLM API 调用次数、token 消耗、平均完成时间，影响对实际使用成本的评估。
- **比较的公平性疑点**：Manual 管线被描述为“固定且未观察数据”的设计，而 EasyBCI 则基于数据指纹自适应，这虽符合产品定位，但对比条件并不完全对等；通用 agent 则可能因缺少领域约束而参数选择不稳定。
- **单研究者/单机部署**：沙箱隔离依赖子进程，多租户场景需额外容器级保护，论文承认了这一点。
